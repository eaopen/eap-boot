# EAP-Boot 技术架构分析

## 项目概述

EAP-Boot 是基于 EAP-Common 框架构建的企业级应用系统，采用现代化的微服务架构设计，提供完整的后台管理系统、基础设施服务和多端用户界面。该项目是 OpenEA 企业应用平台的核心业务实现。

## 技术栈

### 核心技术
- **Java版本**: JDK 21
- **Spring Boot**: 4.1.0
- **Spring Cloud**: 2025.1.2
- **Maven**: 多模块项目管理
- **基础框架**: EAP-Common 3.0.0

### 主要技术组件
- **服务注册发现**: Nacos
- **API网关**: Spring Cloud Gateway
- **数据库**: MySQL + MyBatis Plus
- **缓存**: Redis
- **监控**: Spring Boot Admin
- **容器化**: Docker + Docker Compose

## 项目架构

### 整体架构图

```
eap-boot/
├── eap-server/                   # 单体应用服务
├── eap-gateway/                  # API网关 (微服务模式)
├── eap-module-system/            # 系统管理模块
│   ├── eap-cloud-system-server/ # 系统服务 (微服务)
│   ├── eap-module-system-api/    # 系统API接口
│   └── eap-module-system-biz/    # 系统业务逻辑
├── eap-module-infra/             # 基础设施模块
│   ├── eap-cloud-infra-server/  # 基础设施服务 (微服务)
│   ├── eap-infra-file/           # 文件管理
│   └── eap-infra-job/            # 任务调度
├── eap-ui/                       # 前端项目集合
│   ├── eap-ui-admin-vben/        # 管理后台 (Vue3)
│   ├── eap-ui-admin-uniapp/      # 移动端管理 (UniApp)
│   ├── eap-ui-admin-vue2/        # 管理后台 (Vue2)
│   └── eap-ui-admin-vue3/        # 管理后台 (Vue3)
├── nacos/                        # Nacos配置
└── script/                       # 部署脚本
```

### 部署架构模式

#### 1. 单体模式 (默认)
- **eap-server**: 包含所有业务模块的单体应用
- **适用场景**: 中小型项目、开发测试环境
- **优势**: 部署简单、开发调试方便

#### 2. 微服务模式 (cloud profile)
- **eap-gateway**: API网关，统一入口
- **eap-cloud-system-server**: 系统管理微服务
- **eap-cloud-infra-server**: 基础设施微服务
- **适用场景**: 大型项目、生产环境
- **优势**: 服务独立、可扩展性强

## 核心模块详解

### 1. 系统管理模块 (eap-module-system)

#### 功能职责
- **用户管理**: 用户账号、角色、权限管理
- **组织架构**: 部门、岗位管理

- **登录日志**: 用户登录记录
- **在线用户**: 在线用户监控

- **RBAC权限模型**: 基于角色的访问控制

- **多租户**: SaaS模式多租户支持
- **社交登录**: 支持微信、QQ等第三方登录

7. **安全可靠**: 多层安全防护，细粒度权限控制
8. **多端支持**: 支持Web、移动端等多种客户端

该系统为企业级应用开发提供了完整的解决方案，能够满足不同规模和复杂度的业务需求，是一个生产就绪的企业应用平台。
