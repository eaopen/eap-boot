# 2.9.0.1-rc2 升级入口

本仓与 eap-common 及两个 BOM 使用同一不可变候选版本。先读 eap-common 同版的 `doc/升级指南.md`，先隔离安装 common 再测试和安装本仓。

既有短信单测按 Asia/Shanghai 固定时间断言，跨时区运行完整测试时显式传 `-Duser.timezone=Asia/Shanghai`；这只限定测试环境，不改变应用运行时区。测试 Redis 使用本轮独立端口，不能连业务 Redis。

访问认证仅接受 access token；refresh 仅用于正常刷新端点。积木报表和 WebSocket 调用方需持有有效 access，不得依赖旧 refresh-as-Bearer 行为。旧无 jti JWT 需要重新登录。候选在配套测试、制品校验和下游验证完成前不作生产发布依据。

access 缓存键切换为 `oauth2_access_token:v2:%s`，不再读取旧命名空间中的 refresh 别名。正常 access 可从访问令牌表冷加载，不执行 Redis 全库清理。同一应用所有认证实例应协调升级；不得只回滚其中一个实例重新启用旧认证语义。

## 运行制品验证

不能仅以 Maven 测试通过判断认证补丁可发布。使用打包应用实际 BOOT-INF/lib 的运行依赖和 JDK 17 调用 JWT 签发公开 API，覆盖普通与旧签名分支、空 userKey 和唯一 jti；classpath 不得补入 MapStruct processor 或测试库。rc2 将 JWT 签发中的编译器内部集合类替换为 JDK 集合类，避免编译测试掩盖运行缺类。rc1 保留作对照，不用于发布。
