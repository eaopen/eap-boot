# 2.8.5.1-rc1 升级入口

与同版 common 和两个 BOM 配套。详细基线、平台和迁移说明以 common 的 `doc/升级指南.md` 为准。

历史基线 `52187e6aa303` 不是官方 tag；本候选保留 Spring Boot 3.5.3 及原 2.8.5 平台依赖。使用 JDK17 和独立 Maven 仓完成全量测试、编译和安装；不要覆盖已有制品。测试 Redis 使用独立空闲端口，短信测试夹具按 `-Duser.timezone=Asia/Shanghai` 运行，不改变应用时区。

访问缓存键使用 `oauth2_access_token:v2:%s`，不读取旧命名空间中的 refresh 别名，正常 access 可从真实记录冷加载；不清空 Redis。访问认证只接受 access，refresh 仅用于刷新接口，旧无 jti JWT 需要重新登录。全部实例必须协调切换。

实际包运行检查：`python3 script/verify-jwt-runtime/verify.py <server-jar> --java-home <jdk17-home>`。只有通过候选制品校验和下游回归后，才能按另行批准的流程发布；本候选不含公共制品发布或环境部署授权。
