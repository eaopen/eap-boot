# eap-boot 升级指南

本仓是 eap-common 的消费方，**升级正文以 eap-common 为准**，本文件只写本仓特有事项，避免两份内容漂移：

- 版本矩阵、升级步骤、下游注意事项 Checklist → [`eap-common/doc/升级指南.md`](../eap-common/doc/升级指南.md)
- 发布记录 → 本仓 [CHANGELOG](../CHANGELOG.md)；框架/BOM 层变更见 [eap-common CHANGELOG](../eap-common/CHANGELOG.md)

## 本仓特有事项

1. **先装 eap-common 再编译本仓**：`cd ../eap-common && mvn -DskipTests install`
   （**不要加** `-Dflatten.skip=true`，否则本地仓库 pom 残留 `${revision}`，本仓解析 `eap-boot-common:${revision}` 会失败）。
2. **版本必须同步**：本仓 `pom.xml` 以 `${revision}` 导入 `eap-dependencies` / `eap-cloud-dependencies`，
   `revision` 必须与 eap-common 一致，否则读取 POM 阶段即报 `Non-resolvable import POM`。
3. **验证命令**：`mvn -q -U -DskipTests -Dflatten.skip=true compile`、`mvn -q -Dflatten.skip=true test`。
4. **配置标识**：`eap-server` / `eap-gateway` 的 `eap.info.version` 等应用侧标识，随本仓 `revision` 一起更新。

> 链接说明：本仓与 eap-common 是两个独立 git 仓库，`../eap-common/...` 适用于本地同级检出目录
> （`openea/eap-common` 与 `openea/eap-boot`）；在代码托管网页上请打开 eap-common 仓库的 `doc/升级指南.md`。
